# Development Prompt: DailyBudget App (Phoenix + Next.js Stack)

## Project Overview
Create a daily budget tracking application that helps users manage their daily spending through real-time bank integration. The app should provide a daily spending allowance that automatically updates based on transactions and allows for accumulated savings visualization.

## Technical Stack

### Backend (Phoenix)
- Elixir/Phoenix for the API and real-time features
- PostgreSQL for the database
- Phoenix LiveView for real-time updates (optional for admin dashboard)
- Guardian for JWT authentication
- Absinthe for GraphQL API (optional)
- Ecto for database operations

### Frontend (Next.js)
- Next.js 14+ with App Router
- TypeScript
- TailwindCSS for styling
- Tanstack Query for data fetching
- Zustand for state management
- React Native for iOS app (shared logic with Next.js)

### Infrastructure
- Docker for containerization
- GitHub Actions for CI/CD
- Fly.io or Gigalixir for hosting (both excellent for Phoenix)

### 2. Bank Integration Service
```elixir
# Phoenix Context
defmodule DailyBudget.Banking do
  use GenServer
  
  def start_link(_) do
    GenServer.start_link(__MODULE__, %{})
  end
  
  def init(state) do
    # Set up banking API connections
    {:ok, state}
  end
  
  def handle_info({:new_transaction, transaction}, state) do
    # Broadcast to relevant user channels
    DailyBudgetWeb.Endpoint.broadcast(
      "user:#{transaction.user_id}",
      "transaction",
      transaction
    )
    {:noreply, state}
  end
end
```

### 3. Real-time Transaction Processing
```elixir
# Phoenix Channel
defmodule DailyBudgetWeb.TransactionChannel do
  use Phoenix.Channel
  
  def join("transactions:" <> user_id, _params, socket) do
    if authorized?(socket, user_id) do
      {:ok, socket}
    else
      {:error, %{reason: "unauthorized"}}
    end
  end
  
  def handle_in("new_transaction", payload, socket) do
    # Process new transaction
    broadcast!(socket, "new_transaction", payload)
    {:noreply, socket}
  end
end
```

### 4. Frontend Implementation (Next.js)

```typescript
// app/components/DailyBudget.tsx
import { useEffect } from 'react'
import { useSocket } from '@/hooks/useSocket'
import { useStore } from '@/store'

export const DailyBudget = () => {
  const { socket } = useSocket()
  const { dailyBudget, updateBudget } = useStore()
  
  useEffect(() => {
    if (!socket) return
    
    const channel = socket.channel(`transactions:${userId}`)
    channel.join()
      .receive("ok", resp => console.log("Joined successfully", resp))
      
    channel.on("new_transaction", payload => {
      updateBudget(payload)
    })
    
    return () => {
      channel.leave()
    }
  }, [socket])
  
  return (
    <div className="p-4 rounded-lg bg-white shadow-lg">
      <h2 className="text-2xl font-bold">Today's Budget</h2>
      <div className="mt-4 text-3xl">
        ${dailyBudget.remaining}
        {dailyBudget.saved > 0 && (
          <span className="text-green-500 text-sm ml-2">
            +${dailyBudget.saved} saved
          </span>
        )}
      </div>
    </div>
  )
}
```

## Key Implementation Notes

### Phoenix Backend

1. Use Phoenix PubSub for real-time updates:
   - Set up dedicated channels for transaction updates
   - Implement presence tracking for active users
   - Use Phoenix.Tracker for distributed state

2. Implement Banking Integration:
